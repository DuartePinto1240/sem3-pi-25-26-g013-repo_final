# Glossary


| **Term or Expression** (EN)              | **Termo ou Expressão** (PT)                                                                                      | **Description (Definition and Information)** (EN)                                                                                                                                                  |                                       
|:-----------------------------------------|:-----------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **AnnualProfit**                         | **LucroAnual**                                                                                                   | Represents the profit of a given station for a specific year, used for statistical analysis in US015.                                                                                              |
| **Aisle**                                | **Corredor**                                                                                                     | Path separating rows of bays in a warehouse, also used in distance calculations for picking path sequencing (USEI04).                                                                               |
| **AuditLog**                             | **RegistoDeAuditoria**                                                                                           | File that records all operations on returned products, specifying timestamps, returnId, SKU, action taken, and quantities.                                                                           |
| **Bay**                                  | **Baia**                                                                                                         | Storage location inside a warehouse aisle. Each bay can hold multiple boxes and is managed under FEFO/FIFO rules.                                                                                   |
| **bays.csv**                             | **bays.csv**                                                                                                     | Input dataset defining warehouse structure: warehouseId, aisle, bay, and capacity of boxes, used to initialize the storage model in memory.                                                          |
| **BestFitDecreasing (BFD)**              | **MelhorAjusteDecrescente (BFD)**                                                                                 | Packing heuristic used in USEI03. Items are sorted by weight (descending) and placed in the trolley that will leave the least remaining capacity unused.                                             |
| **Box**                                  | **Caixa**                                                                                                        | Smallest inventory unit transported in wagons and stored in warehouse bays, each with SKU, quantity, and possibly expiry date (perishables).                                                        |
| **Boxcar**                               | **VagãoFechado**                                                                                                 | Type of wagon used to transport general goods; part of Rolling Stock in the railway domain.                                                                                                         |
| **Capacity**                             | **Capacidade**                                                                                                   | Constraint of wagons, bays, or trolleys defining the maximum weight or volume allowed. Used in planning and allocation.                                                                              |
| **DeterministicSweep**                   | **PercursoDeterminístico**                                                                                       | Picking path sequencing strategy that sorts bays in ascending order of aisles, used in USEI04.                                                                                                      |
| **Dock**                                 | **DocaDeDescarga**                                                                                               | Access point in the terminal where wagons unload cargo into warehouses for storage and later dispatch.                                                                                              |
| **DoubleTrack**                          | **LinhaDupla**                                                                                                   | Line segment type where trains can circulate in opposite directions simultaneously without stopping at stations.                                                                                    |
| **EligibilityStatus**                    | **EstadoDeElegibilidade**                                                                                        | Classification of an order line after allocation: ELIGIBLE, PARTIAL, or UNDISPATCHABLE, depending on available inventory.                                                                            |
| **FEFO/FIFO**                            | **FEFO/FIFO**                                                                                                    | Inventory management rules applied in unloading and dispatch: *First-Expired-First-Out* for perishables and *First-In-First-Out* for non-perishables.                                                |
| **Flatcar**                              | **Plataforma**                                                                                                   | Type of wagon used to carry containers, vehicles, or heavy machinery.                                                                                                                                |
| **Freight**                              | **Carga**                                                                                                        | A set of wagons transported from one station to another, defining a logistical flow within the railway network managed by the system.                                                               |
| **FreightYard**                          | **PátioDeMercadorias**                                                                                           | Area inside a terminal or station where wagons are sorted, parked, or assembled before being dispatched in the network.                                                                             |
| **Gauge**                                | **Bitola**                                                                                                       | Width of a railway track. A property of line segments and rolling stock, influencing compatibility of locomotives and wagons.                                                                        |
| **HopperCar**                            | **VagãoGraneleiro**                                                                                              | Type of wagon designed to transport coal, grains, or minerals in bulk.                                                                                                                               |
| **In-Memory Data Structures**            | **EstruturasDeDadosEmMemória**                                                                                   | Data representation of all imported CSV records after validation; basis for all algorithms (allocation, picking, path sequencing, returns) in Sprint 1.                                               |
| **items.csv**                            | **items.csv**                                                                                                    | Input dataset with master data of products (SKU, name, category, unit, volume, unitWeight) required for validation and inventory operations.                                                         |
| **Line**                                 | **Linha**                                                                                                        | Railway route composed of one or more line segments, connecting stations and managed by an owner.                                                                                                   |
| **LineSegment**                          | **SegmentoDeLinha**                                                                                              | A portion of a railway line connecting two points, with properties like gauge, electrification, and track type (single/double), used in planning and statistics in the project.                      |
| **Locomotive**                           | **Locomotiva**                                                                                                   | Engine unit of a train, diesel or electric, responsible for pulling wagons; defined by attributes like power, acceleration, gauge, and fuel capacity.                                                |
| **NearestNeighbour**                     | **VizinhoMaisPróximo**                                                                                           | Picking path sequencing strategy that always chooses the next bay with the shortest distance from the current position, used in USEI04.                                                              |
| **Operator**                             | **Operador**                                                                                                     | Company that owns and operates locomotives or wagons within the railway infrastructure.                                                                                                              |
| **Order**                                | **Encomenda**                                                                                                    | Request containing one or more order lines, each line specifying a SKU and quantity to be dispatched from warehouse stock.                                                                           |
| **OrderLine**                            | **LinhaDeEncomenda**                                                                                             | Single item request within an order, specifying SKU, quantity, and due date; used in allocation and picking planning.                                                                               |
| **order_lines.csv**                      | **order_lines.csv**                                                                                              | Input dataset containing detailed order lines (orderId, lineNo, SKU, qty), used for order allocation (USEI02).                                                                                       |
| **orders.csv**                           | **orders.csv**                                                                                                   | Input dataset containing orders (orderId, dueDate, priority), used for allocation and picking planning.                                                                                              |
| **Owner**                                | **Proprietário**                                                                                                 | Entity responsible for a railway line. Owners maintain their segments but allow usage by other operators’ trains.                                                                                    |
| **PackingHeuristic**                     | **HeurísticaDeEmpacotamento**                                                                                    | Strategy used in USEI03 to allocate order lines to trolleys: First Fit (FF), First Fit Decreasing (FFD), and Best Fit Decreasing (BFD).                                                              |
| **Path**                                 | **Percurso**                                                                                                     | Ordered list of stations through which a freight passes from origin to destination.                                                                                                                 |
| **Picker**                               | **Recolhedor**                                                                                                   | User who executes the physical picking of items from warehouse bays according to the picking plan and picking path strategy.                                                                         |
| **PickingPath**                          | **PercursoDeRecolha**                                                                                            | Optimized sequence of warehouse bay visits for picking items, calculated using deterministic or nearest-neighbour strategies to minimize distance.                                                   |
| **PickingPlan**                          | **PlanoDeRecolha**                                                                                               | Plan generated to collect products from warehouse bays to fulfill orders, considering trolley capacity and optimization heuristics defined in Sprint 1.                                              |
| **PressureGasCar**                       | **VagãoDeGasesLiquefeitos**                                                                                      | Wagon designed to transport liquefied gases (e.g., propane, butane) under pressure.                                                                                                                  |
| **QualityOperator**                      | **OperadorDeQualidade**                                                                                          | User responsible for managing product returns, inspecting items in quarantine, and deciding whether they are restocked or discarded.                                                                 |
| **RailwayGraph**                         | **GrafoFerroviário**                                                                                             | Data structure modeling stations and line segments as nodes and edges, supporting pathfinding, maintenance routes, and infrastructure analysis within the simulation.                               |
| **RailwayInfrastructure**                | **InfraestruturaFerroviária**                                                                                    | Physical elements of the railway system such as tracks, stations, freight yards, and terminals, which enable the circulation of trains and cargo handling in the project.                           |
| **RefrigeratedCar**                      | **VagãoFrigorífico**                                                                                             | Wagon type with cooling systems used to transport perishable goods.                                                                                                                                 |
| **Return**                               | **Devolução**                                                                                                    | Cargo item returned to the terminal, requiring inspection before reintroduction into inventory or disposal.                                                                                         |
| **ReturnQuarantine**                     | **QuarentenaDeDevoluções**                                                                                       | Temporary stage where returned goods are inspected before reintegration or disposal, with audit logs ensuring traceability of actions taken.                                                         |
| **RollingStock**                         | **MaterialCirculante**                                                                                           | Vehicles that circulate on the railway, including locomotives and wagons, each with attributes (type, gauge, capacity, operator) relevant to planning and cargo operations.                          |
| **Route**                                | **Rota**                                                                                                         | Complete connection between an origin and destination station, possibly including several paths and freights.                                                                                        |
| **Scheduler/Planner**                    | **Planeador**                                                                                                    | System user responsible for analyzing and creating timetables, routes, and allocations for trains and warehouse operations.                                                                          |
| **SingleTrack**                          | **LinhaÚnica**                                                                                                   | Line segment type where trains share the same track in both directions, requiring coordination at stations or sidings.                                                                               |
| **SKU**                                  | **SKU (Unidade de Manutenção de Stock)**                                                                          | Unique identifier of a product type managed in wagons and warehouses, essential for order allocation, inventory management, and return processing in the project.                                    |
| **Station**                              | **Estação**                                                                                                      | Node in the railway infrastructure where trains can stop, load/unload cargo, or cross in the case of single-track lines.                                                                            |
| **TankCar**                              | **VagãoTanque**                                                                                                  | Wagon type used to transport liquids, chemicals, or fuels. Includes subtypes like Mineral Oil Cars and Chemical Tank Cars.                                                                           |
| **Terminal**                             | **Terminal**                                                                                                     | Specialized station with logistics functions, including unloading docks, warehouses, and intermodal connections, central in Sprint 1 cargo handling operations.                                     |
| **TerminalOperator**                     | **OperadorDeTerminal**                                                                                           | User responsible for wagon unloading, warehouse stock management, and ensuring FEFO/FIFO compliance during cargo handling.                                                                          |
| **Trolley**                              | **CarrinhoDeRecolha**                                                                                            | Capacity-bounded cart used by pickers to collect items from warehouse bays; central in USEI03 picking plan heuristics.                                                                               |
| **Validation Rules**                     | **RegrasDeValidação**                                                                                            | Set of constraints applied when importing CSV files (e.g., rejecting unknown SKUs, invalid quantities, missing dates, non-unique boxIds).                                                            |
| **Wagon**                                | **Vagão**                                                                                                        | Freight vehicle attached to locomotives, designed for specific cargo types (e.g., boxcar, flatcar, tanker, hopper, refrigerated). Each wagon has payload and volume constraints.                      |
| **wagons.csv**                           | **wagons.csv**                                                                                                   | Input dataset with information on wagons and their transported boxes (boxId, SKU, qty, expiryDate, receivedAt), used to initialize inventory.                                                        |
| **Warehouse**                            | **Armazém**                                                                                                      | Storage facility connected to unloading docks, divided into aisles and bays, used to store products unloaded from wagons.                                                                           |
| **WarehouseBay**                         | **BaiaDeArmazém**                                                                                                | Storage unit inside a warehouse aisle at a terminal, where boxes unloaded from wagons are stored and organized following FEFO/FIFO rules.                                                           |
