# Glossary

| **Term or Expression**               | **Termo ou Expressão**                   | **Description (Definition and Information)**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|:-------------------------------------|:-----------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **AnnualProfit**                     | **LucroAnual**                           | Represents the profit of a given [Station](#station) for a specific year, used for statistical analysis in [AnnualProfit](#annualprofit).                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Aisle**                            | **Corredor**                             | Path separating rows of [Bay](#bay)s in a [Warehouse](#warehouse), also used in distance calculations for [PickingPath](#pickingpath) sequencing ([DeterministicSweep](#deterministicsweep), [NearestNeighbour](#nearestneighbour)).                                                                                                                                                                                                                                                                                                           |
| **AuditLog**                         | **RegistoDeAuditoria**                   | File that records all operations on [Return](#return)s, specifying timestamps, returnId, [SKU](#sku), action taken, and quantities.                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Batch**                            | **Lote**                                 | A specific group of [Boxes](#boxes) of the same [SKU](#sku) that were produced or received at the same time, often with the same expiration date (essential for [FEFO/FIFO](#fefo/fifo) management).                                                                                                                                                                                                                                                                                                                                           |
| **Bay**                              | **Baia**                                 | Storage location inside a [Warehouse](#warehouse) [Aisle](#aisle). Each [Bay](#bay) can hold multiple [Box](#box)es and is managed under [FEFO/FIFO](#fefofifo) rules.                                                                                                                                                                                                                                                                                                                                                                         |
| **bays.csv**                         | **bays.csv**                             | Input dataset defining [Warehouse](#warehouse) structure: warehouseId, aisle, bay, and capacity of [Box](#box)es, used to initialize the storage model in memory.                                                                                                                                                                                                                                                                                                                                                                              |
| **BestFitDecreasing (BFD)**          | **MelhorAjusteDecrescente (BFD)**        | Packing heuristic used in [PackingHeuristic](#packingheuristic) ([USEI03](#usei03)). Items are sorted by weight (descending) and placed in the [Trolley](#trolley) that will leave the least remaining capacity unused.                                                                                                                                                                                                                                                                                                                        |
| **Bridges**                          | **Pontes**                               | Engineering structures in [RailwayInfrastructure](#railwayinfrastructure) that allow [Train](#train)s to cross obstacles like rivers or valleys.                                                                                                                                                                                                                                                                                                                                                                                               |
| **Box**                              | **Caixa**                                | Smallest inventory unit transported in [Wagon](#wagon) and stored in [WarehouseBay](#warehousebay), each with [SKU](#sku), quantity, and possibly expiry date ([perishables](#fefofifo)).                                                                                                                                                                                                                                                                                                                                                      |
| **Boxcar**                           | **VagãoFechado**                         | Type of [Wagon](#wagon) used to transport general goods; part of [RollingStock](#rollingstock) in the [Railway](#railway) domain.                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Building**                         | **Edifício**                             | Structural unit associated with a [Terminal](#terminal) or [Warehouse](#warehouse) , characterized by capacity, status, and operating cost, used for storage or maintenance activities.                                                                                                                                                                                                                                                                                                                                                        |
| **Bulk goods**                       | **Mercadorias a granel**                 | Unpackaged large-volume commodities such as coal, grain, or minerals that are transported in bulk form rather than in [Container](#container).                                                                                                                                                                                                                                                                                                                                                                                                 |
| **Capacity**                         | **Capacidade**                           | Constraint of [Wagon](#wagon), [Bay](#bay), or [Trolley](#trolley) defining the maximum weight or volume allowed. Used in planning and allocation.                                                                                                                                                                                                                                                                                                                                                                                             |
| **Cargo**                            | **Carga**                                | Goods or materials transported via freight services, typically using [Container](#container) on [Train](#train), [Truck](#truck), or [Ship](#ship) within the intermodal logistics network.                                                                                                                                                                                                                                                                                                                                                    |
| **Cities**                           | **Cidades**                              | Major population and economic centers that function as key endpoints or hubs in the [Railway](#railway) network, often containing [FreightYard](#freightyard) and [Terminal](#terminal)s.                                                                                                                                                                                                                                                                                                                                                      |
| **Chemical Tank Cars**               | **Cisternas para Produtos Químicos**     | A specialized type of [TankCar](#tankcar) designed for transporting chemicals with specific requirements, such as varying densities and high purity.                                                                                                                                                                                                                                                                                                                                                                                           |
| **CrossingOperation**                | **OperaçãoDeTravessia**                  | Railway maneuver performed on [SingleTrack](#singletrack) lines to allow two [Train](#train)s traveling in opposite directions to pass each other safely. One train waits at a [Siding](#siding) or [Station](#station) while the other moves through. These operations are essential for traffic management, timetable coordination ([TrainSchedule](#trainschedule)), and ensuring efficient use of line capacity.                                                                                                                           |
| **Depot**                            | **"Terminal" menor**                     | Facility for maintaining, parking, or repairing locomotives and wagons; may connect directly to [Warehouse](#warehouse)s.                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **DeterministicSweep**               | **PercursoDeterminístico**               | [PickingPath](#pickingpath) sequencing strategy that sorts [Bay](#bay)s in ascending order of [Aisle](#aisle), used in [USEI04](#usei04).                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Dock**                             | **DocaDeDescarga**                       | Access point in the [Terminal](#terminal) where [Wagon](#wagon)s unload [Cargo](#cargo) into [Warehouse](#warehouse) for storage and later dispatch.                                                                                                                                                                                                                                                                                                                                                                                           |
| **DoubleTrack**                      | **LinhaDupla**                           | Line segment type where [Train](#train)s can circulate in opposite directions simultaneously without stopping at [Station](#station)s.                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Eletric lines**                    | **Linha Elétrica**                       | [Railway](#railway) line segments that are equipped with an overhead catenary system or a third rail to supply power to [Locomotive](#locomotive)s.                                                                                                                                                                                                                                                                                                                                                                                            |
| **EligibilityStatus**                | **EstadoDeElegibilidade**                | Classification of an [OrderLine](#orderline) after allocation: ELIGIBLE, PARTIAL, or UNDISPATCHABLE, depending on available [Inventory](#inventory).                                                                                                                                                                                                                                                                                                                                                                                           |
| **ExpiryTracking**                   | **ControloDeValidade**                   | Mechanism that monitors the expiry dates of stored [Box](#box)es or [Item](#item)s, ensuring compliance with FEFO policies and reducing waste.                                                                                                                                                                                                                                                                                                                                                                                                 |
| **Facility**                         | **Instalação**                           | A place equipped for a specific purpose, such as a [freight yard](#freightyard), [station](#station), or [terminal](#terminal), connected to [railway](#railway) infrastructure to support logistics and [cargo](#cargo) operations.                                                                                                                                                                                                                                                                                                           |
| **FEFO/FIFO**                        | **FEFO/FIFO**                            | Inventory management rules applied in unloading and dispatch: *First-Expired-First-Out* for [perishable](#fefofifo) [Box](#box)es and *First-In-First-Out* for non-perishable [Box](#box)es.                                                                                                                                                                                                                                                                                                                                                   |
| **Flatcar**                          | **Plataforma**                           | Type of [Wagon](#wagon) used to carry [Container](#container)s, vehicles, or heavy machinery.                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Freight**                          | **Carga**                                | A set of [Wagon](#wagon)s transported from one [Station](#station) to another, defining a logistical flow within the [Railway](#railway) network.                                                                                                                                                                                                                                                                                                                                                                                              |
| **Freight Carriages**                | **Vagões de Carga**                      | The vehicles in a [Train](#train), also called [Wagon](#wagon)s, that are designed to carry specific types of [Cargo](#cargo), such as [Container](#container)s, liquids, or bulk materials.                                                                                                                                                                                                                                                                                                                                                   |
| **FreightManager**                   | **Gestor de Carga**                      | Role responsible for planning, coordinating, and supervising [Freight](#freight) transport operations. Manages the assignment of [Wagon](#wagon)s and [Locomotive](#locomotive)s to [Freight](#freight)s, verifies [Gauge](#gauge) compatibility, ensures compositions respect capacity constraints, and oversees routing between [Station](#station)s and [Terminal](#terminal)s. Acts as a key entity linking [RollingStock](#rollingstock) availability, [RailwayInfrastructure](#railwayinfrastructure), and cargo transport requirements. |
| **Freight Trains**                   | **Comboios de Mercadoria**               | [Train](#train)s designed to transport [Cargo](#cargo), raw materials, or [Container](#container)s instead of [Passengers](#passengers).                                                                                                                                                                                                                                                                                                                                                                                                       |
| **FreightYard**                      | **PátioDeMercadorias**                   | Area inside a [Terminal](#terminal) or [Station](#station) where [Wagon](#wagon)s are sorted, parked, or assembled before being dispatched in the network.                                                                                                                                                                                                                                                                                                                                                                                     |
| **Gauge**                            | **Bitola**                               | Width of a [Track](#track). A property of line segments and [RollingStock](#rollingstock), influencing compatibility of [Locomotive](#locomotive)s and [Wagon](#wagon)s.                                                                                                                                                                                                                                                                                                                                                                       |
| **Grain silos**                      | **Silos de Grãos**                       | Specialized storage structures for bulk grains, located at [Railway](#railway) [Terminal](#terminal)s, facilitating the efficient loading and unloading of [HopperCar](#hoppercar)s.                                                                                                                                                                                                                                                                                                                                                           |
| **HopperCar**                        | **VagãoGraneleiro**                      | Type of [Wagon](#wagon) designed to transport coal, grains, or minerals in bulk.                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Industrial Zones**                 | **Zonas Industriais**                    | Areas designated for manufacturing and logistics, directly connected to [RailwayInfrastructure](#railwayinfrastructure) and [Terminal](#terminal)s to support efficient [Cargo](#cargo) transport within [Supply chains](#supply-chains).                                                                                                                                                                                                                                                                                                      |
| **IntermodalConnection**             | **LigacãoIntermodal**                    | Represents a link between two [Terminal](#terminal)s of different [TransportMode](#tranportmode)s (e.g., rail–sea or rail–road), with origin/destination and transfer time.                                                                                                                                                                                                                                                                                                                                                                    |
| **Intermodal Terminal**              | **Terminal Intermodal**                  | A [Terminal](#terminal) where [Cargo](#cargo) is transferred between different modes of transport — rail, road, or sea — without handling the goods themselves.                                                                                                                                                                                                                                                                                                                                                                                |
| **InventoryManagement**              | **GestãoDeInventário**                   | Subsystem responsible for monitoring stock levels, recording movements, and tracking utilization and capacity of [Warehouse](#warehouse) areas.                                                                                                                                                                                                                                                                                                                                                                                                |
| **InventoryMovement**                | **MovimentoDeInventário**                | Record that documents each transfer of [Item](#item)s or [Box](#box) es between locations, including origin, destination, quantity, and timestamp, forming the base of stock tracking.                                                                                                                                                                                                                                                                                                                                                         |
| **Item**                             | **Item**                                 | Represents a product reference managed by SKU, with name, category, volume, and unit weight; serves as a master entity for [Box](#box), [Order](#order) , and [Inventory](#inventory) operations.                                                                                                                                                                                                                                                                                                                                              |
| **items.csv**                        | **items.csv**                            | Input dataset with master data of [Box](#box)es ([SKU](#sku), name, category, unit, volume, unitWeight) required for validation and [Inventory](#inventory) operations.                                                                                                                                                                                                                                                                                                                                                                        |
| **Line**                             | **Linha**                                | [Railway](#railway) route composed of one or more [LineSegment](#linesegment)s, connecting [Station](#station)s and managed by an [Owner](#owner).                                                                                                                                                                                                                                                                                                                                                                                             |
| **LineSegment**                      | **SegmentoDeLinha**                      | A portion of a [Line](#line) connecting two points, with properties like [Gauge](#gauge), electrification, and track type ([SingleTrack](#singletrack)/[DoubleTrack](#doubletrack)), used in planning and statistics in the project.                                                                                                                                                                                                                                                                                                           |
| **Locomotive**                       | **Locomotiva**                           | Engine unit of a [Train](#train), diesel or electric, responsible for pulling [Wagon](#wagon)s; defined by attributes like power, acceleration, [Gauge](#gauge), and fuel capacity.                                                                                                                                                                                                                                                                                                                                                            |
| **LocomotiveModel**                  | **ModeloDeLocomotiva**                   | Defines the technical specifications of a [Locomotive](#locomotive), including make, type, power, acceleration, fuel capacity, and compatible [Gauge](#gauge). Used to categorize locomotives by design and performance parameters.                                                                                                                                                                                                                                                                                                            |
| **LocomotiveType**                   | **TipoDeLocomotiva**                     | Enumeration classifying locomotives as Diesel or Electric, influencing operational range, speed, and maintenance requirements.                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **Manufacture products**             | **Fabricar produtos**                    | To use machines, labour, and [Raw materials](#raw-materials) in an industrial setting to create finished [Box](#box)es that can be transported or distributed through the [Supply chains](#supply-chains).                                                                                                                                                                                                                                                                                                                                     |
| **Mineral Oil Cars**                 | **Vagões para Óleos Minerais**           | A type of [TankCar](#tankcar) specifically designed for the transport of various petrochemicals and mineral oils.                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Multiple Freight**                 | **Fretes Múltiplos**                     | A [Train](#train) composition or [Route](#route) that is designed to transport several distinct sets of [Wagon](#wagon)s, potentially with different origins and destinations, in a single journey.                                                                                                                                                                                                                                                                                                                                            |
| **NearestNeighbour**                 | **VizinhoMaisPróximo**                   | [PickingPath](#pickingpath) sequencing strategy that always chooses the next [Bay](#bay) with the shortest distance from the current position, used in [USEI04](#usei04).                                                                                                                                                                                                                                                                                                                                                                      |
| **Non-functional Requirement (NFR)** | **Requisito Não-Funcional (RNF)**        | A constraint on how the system must be built, rather than what it should do. Includes attributes such as performance, security, usability, or technology requirements (e.g., using Java or PL/SQL).                                                                                                                                                                                                                                                                                                                                            |
| **Operator**                         | **Operador**                             | Company that owns and operates [Locomotive](#locomotive)s or [Wagon](#wagon)s within the [RailwayInfrastructure](#railwayinfrastructure).                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Order**                            | **Encomenda**                            | Request containing one or more [OrderLine](#orderline)s, each specifying a [SKU](#sku) and quantity to be dispatched from [Warehouse](#warehouse) stock.                                                                                                                                                                                                                                                                                                                                                                                       |
| **OrderLine**                        | **LinhaDeEncomenda**                     | Single item request within an [Order](#order), specifying [SKU](#sku), quantity, and due date; used in allocation and picking planning.                                                                                                                                                                                                                                                                                                                                                                                                        |
| **order_lines.csv**                  | **order_lines.csv**                      | Input dataset containing detailed [OrderLine](#orderline)s (orderId, lineNo, [SKU](#sku), qty), used for [Order](#order) allocation ([USEI02](#usei02)).                                                                                                                                                                                                                                                                                                                                                                                       |
| **orders.csv**                       | **orders.csv**                           | Input dataset containing [Order](#order)s (orderId, dueDate, priority), used for allocation and [PickingPlan](#pickingplan) planning.                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Owner**                            | **Proprietário**                         | Entity responsible for a [Line](#line). [Owner](#owner)s maintain their segments but allow usage by other [Operator](#operator)s’ [Train](#train)s.                                                                                                                                                                                                                                                                                                                                                                                            |
| **PackingHeuristic**                 | **HeurísticaDeEmpacotamento**            | Strategy used in [USEI03](#usei03) to allocate [OrderLine](#orderline)s to [Trolley](#trolley)s: First Fit (FF), First Fit Decreasing (FFD), and Best Fit Decreasing (BFD).                                                                                                                                                                                                                                                                                                                                                                    |
| **Path**                             | **Percurso**                             | Ordered list of [Station](#station)s through which [Freight](#freight) passes from origin to destination.                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Passengers**                       | **Passageiros**                          | People who travel by [Train](#train) or other transport modes rather than [Cargo](#cargo).                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Payload**                          | **Carga Útil**                           | The maximum weight of [Cargo](#cargo) that a [Wagon](#wagon) is designed to carry, excluding the [Wagon](#wagon)'s own tare weight.                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Picker**                           | **Recolhedor**                           | User who executes the physical picking of [Box](#box)es from [WarehouseBay](#warehousebay)s according to the [PickingPlan](#pickingplan) and [PickingPath](#pickingpath) strategy.                                                                                                                                                                                                                                                                                                                                                             |
| **PickingPath**                      | **PercursoDeRecolha**                    | Optimized sequence of [WarehouseBay](#warehousebay) visits for collecting [Box](#box)es, calculated using deterministic or nearest-neighbour strategies to minimize distance.                                                                                                                                                                                                                                                                                                                                                                  |
| **PickingPlan**                      | **PlanoDeRecolha**                       | Plan generated to collect [Box](#box)es from [WarehouseBay](#warehousebay)s to fulfill [Order](#order)s, considering [Trolley](#trolley) capacity and optimization heuristics.                                                                                                                                                                                                                                                                                                                                                                 |
| **PressureGasCar**                   | **VagãoDeGasesLiquefeitos**              | [Wagon](#wagon) designed to transport liquefied gases (e.g., propane, butane) under pressure.                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Port**                             | **Porto**                                | An intermodal [Terminal](#terminal) where [Cargo](#cargo) is transferred between [Ship](#ship)s and [Train](#train)s, serving as a key connection point between maritime and [Railway](#railway) networks.                                                                                                                                                                                                                                                                                                                                     |
| **QualityOperator**                  | **OperadorDeQualidade**                  | User responsible for managing [Return](#return)s, inspecting [Box](#box)es in [ReturnQuarantine](#returnquarantine), and deciding whether they are restocked or discarded.                                                                                                                                                                                                                                                                                                                                                                     |
| **RailLine**                         | **LinhaFerooviária**                     | Logical grouping of [LineSegment](#linesegment)s forming a complete route between [Station](#station)s, managed by a specific [Owner](#owner) or [Operator](#operator) .                                                                                                                                                                                                                                                                                                                                                                       |
| **Railway**                          | **Ferrovia**                             | System for transporting [Cargo](#cargo) by [Train](#train), including [Track](#track)s, [Terminal](#terminal)s, [Locomotive](#locomotive)s, [Wagon](#wagon)s, and operations that ensure efficient and sustainable logistics.                                                                                                                                                                                                                                                                                                                  |
| **RailwayGraph**                     | **GrafoFerroviário**                     | Data structure modeling [Station](#station)s and [LineSegment](#linesegment)s as nodes and edges, supporting pathfinding, maintenance routes, and infrastructure analysis within the simulation.                                                                                                                                                                                                                                                                                                                                               |
| **RailwayInfrastructure**            | **InfraestruturaFerroviária**            | Physical elements of the [Railway](#railway) system such as [Track](#track)s, [Station](#station)s, [FreightYard](#freightyard)s, and [Terminal](#terminal)s, which enable the circulation of [Train](#train)s and [Cargo](#cargo) handling.                                                                                                                                                                                                                                                                                                   |
| **Raw materials**                    | **Matérias-primas**                      | Basic natural resources or unprocessed materials used to manufacture [Box](#box)es or supply industries, such as wood, iron ore, or crude oil.                                                                                                                                                                                                                                                                                                                                                                                                 |
| **Refrigerated Areas**               | **Áreas Refrigeradas**                   | Specially designed storage zones within [Terminal](#terminal)s or [RefrigeratedCar](#refrigeratedcar)s that maintain a low temperature to preserve perishable [Box](#box)es during transport and storage.                                                                                                                                                                                                                                                                                                                                      |
| **RefrigeratedCar**                  | **VagãoFrigorífico**                     | [Wagon](#wagon) type with cooling systems used to transport perishable [Box](#box)es.                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Return**                           | **Devolução**                            | [Cargo](#cargo) item returned to the [Terminal](#terminal), requiring inspection before reintroduction into [Inventory](#inventory) or disposal.                                                                                                                                                                                                                                                                                                                                                                                               |
| **ReturnQuarantine**                 | **QuarentenaDeDevoluções**               | Temporary stage where returned [Box](#box)es are inspected before reintegration or disposal, with [AuditLog](#auditlog)s ensuring traceability of actions taken.                                                                                                                                                                                                                                                                                                                                                                               |
| **RollingStock**                     | **MaterialCirculante**                   | Vehicles that circulate on the [Railway](#railway), including [Locomotive](#locomotive)s and [Wagon](#wagon)s, each with attributes (type, [Gauge](#gauge), [Capacity](#capacity), [Operator](#operator)) relevant to planning and [Cargo](#cargo) operations.                                                                                                                                                                                                                                                                                 |
| **Route**                            | **Rota**                                 | Complete connection between an origin and destination [Station](#station), possibly including several [Path](#path)s and [Freight](#freight)s.                                                                                                                                                                                                                                                                                                                                                                                                 |
| **Scheduler/Planner**                | **Planeador**                            | System user responsible for analyzing and creating timetables, [Route](#route)s, and allocations for [Train](#train)s and [Warehouse](#warehouse) operations.                                                                                                                                                                                                                                                                                                                                                                                  |
| **Siding**                           | **Linha de Apartadero**                  | A short secondary track adjacent to the main line, used for parking [Wagons](#wagons), sorting, or allowing [Trains](#trains) on a [SingleTrack](#singletrack) to pass or overtake each other.                                                                                                                                                                                                                                                                                                                                                 |
| **Single Freight**                   | **Frete Simples**                        | A [Train](#train) composition or [Route](#route) dedicated to transporting one set of [Wagon](#wagon)s from a single origin [Station](#station) to a single destination [Station](#station).                                                                                                                                                                                                                                                                                                                                                   |
| **SingleTrack**                      | **LinhaÚnica**                           | Line segment type where [Train](#train)s share the same [Track](#track) in both directions, requiring coordination at [Station](#station)s or sidings.                                                                                                                                                                                                                                                                                                                                                                                         |
| **SKU**                              | **SKU (Unidade de Manutenção de Stock)** | Unique identifier of a [Box](#box) type managed in [Wagon](#wagon)s and [Warehouse](#warehouse)s, essential for [Order](#order) allocation, [Inventory](#inventory) management, and [Return](#return) processing.                                                                                                                                                                                                                                                                                                                              |
| **Station**                          | **Estação**                              | Node in the [RailwayInfrastructure](#railwayinfrastructure) where [Train](#train)s can stop, load/unload [Cargo](#cargo), or cross in the case of [SingleTrack](#singletrack) lines.                                                                                                                                                                                                                                                                                                                                                           |
| **StationService**                   | **ServiçoDeEstações**                    | Component responsible for managing [Station](#station) data and [ValidationLog](#validatelog) records, supporting creation, update, and consistency verification of station information.                                                                                                                                                                                                                                                                                                                                                       |
| **Supply chains**                    | **Cadeias de abastecimento**             | The network of organizations, resources, and processes involved in producing, transporting, and delivering [Cargo](#cargo) from [Raw materials](#raw-materials) suppliers to final users.                                                                                                                                                                                                                                                                                                                                                      |
| **TankCar**                          | **VagãoTanque**                          | [Wagon](#wagon) type used to transport liquids, chemicals, or fuels. Includes subtypes like [Mineral Oil Cars](#mineral-oil-cars) and [Chemical Tank Cars](#chemical-tank-cars).                                                                                                                                                                                                                                                                                                                                                               |
| **Tare Weight**                      | **Tara**                                 | The empty weight of a [Wagon](#wagon), [Box](#box), or [Trolley](#trolley) (body, container, etc.) by itself, which must be subtracted from the total [Capacity](#capacity) to determine the maximum [Payload](#payload).                                                                                                                                                                                                                                                                                                                      |
| **Terminal**                         | **Terminal**                             | Specialized [Station](#station) with logistics functions, including unloading [Dock](#dock)s, [Warehouse](#warehouse)s, and intermodal connections, central in Sprint 1 [Cargo](#cargo) handling operations.                                                                                                                                                                                                                                                                                                                                   |
| **TerminalOperator**                 | **OperadorDeTerminal**                   | User responsible for [Wagon](#wagon) unloading, [Warehouse](#warehouse) stock management, and ensuring [FEFO/FIFO](#fefofifo) compliance during [Cargo](#cargo) handling.                                                                                                                                                                                                                                                                                                                                                                      |
| **TimeZoneGroup**                    | **GrupoDeFusoHorário**                   | Classification grouping stations by time zone (e.g., CET, WET/GMT, EET), used for scheduling and synchronizing [TrainSchedule](#trainschedule)s across different regions.                                                                                                                                                                                                                                                                                                                                                                      |
| **Track**                            | **Via férrea**                           | Physical [Railway](#railway) pathway where [Train](#train)s run, made up of rails, sleepers, and ballast, and forms the basic infrastructure of the [Railway](#railway) network.                                                                                                                                                                                                                                                                                                                                                               |
| **Track Cam**                        | **Bogies**                               | The undercarriage assemblies underneath [Locomotive](#locomotive)s and [Wagon](#wagon)s, each containing wheelsets, which distribute the vehicle's weight and help it navigate curves.                                                                                                                                                                                                                                                                                                                                                         |
| **TrackType**                        | **TipoDeVia**                            | Enumeration indicating whether a [LineSegment](#linesegment) is Single or Double, affecting traffic flow and scheduling.                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Train**                            | **Comboio**                              | Set of coupled [Railway](#railway) vehicles, usually a [Locomotive](#locomotive) (or several) pulling [Wagon](#wagon)s, used to transport [Cargo](#cargo) across the [Railway](#railway) network.                                                                                                                                                                                                                                                                                                                                              |
| **TrainOperator**                    | **OperadorDeComboio**                    | Entity or company that owns and manages [Train](#train)s and [Wagon](#wagon)s, ensuring operation in compliance with regulations and maintenance standards.                                                                                                                                                                                                                                                                                                                                                                                    |
| **TrainSchedule**                    | **HorárioDeComboio**                     | Defines a [Train](#train)’s timetable, including departure and arrival [Station](#station)s and timestamps, essential for route planning and logistics synchronization.                                                                                                                                                                                                                                                                                                                                                                        |
| **TransportMode**                    | **ModoDeTransporte**                     | Enumeration identifying the mode used for cargo movement: Rail, Road, Sea, or Air. Determines operational constraints and compatibility in [IntermodalConnection](#intermodalconnection).                                                                                                                                                                                                                                                                                                                                                      |
| **Trolley**                          | **CarrinhoDeRecolha**                    | Capacity-bounded cart used by [Picker](#picker)s to collect [Box](#box)es from [WarehouseBay](#warehousebay)s; central in [PackingHeuristic](#packingheuristic) planning.                                                                                                                                                                                                                                                                                                                                                                      |
| **Tunnels**                          | **Túneis**                               | Underground passages in [RailwayInfrastructure](#railwayinfrastructure) that allow [Train](#train)s to cross mountains or other obstacles.                                                                                                                                                                                                                                                                                                                                                                                                     |
| **User Story (US)**                  | **História de Utilizador (HU)**          | An informal description of a system feature written from the user's point of view (e.g., "As a *Scheduler/Planner*, I want to calculate the shortest [PickingPath](#pickingpath). It serves as the basis for defining use cases and functional requirements.                                                                                                                                                                                                                                                                                   |
